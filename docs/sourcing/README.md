# Посуд / набори — внутрішнє наповнення

CEO supplement Task19,2026-10-30 Kyiv. Основа магазину — чай. Старт посуду/наборів: добір і перезамовлення у продавців України; надалі Китай і власне наявне зберігання. Власні чабані з гравіюванням — концепція.

`PRODUCT_DRAFT_TEMPLATE.json` — порожня форма, НЕ товар. Копіювати в приватний операційний реєстр. Реальні закупівельні ціни, документи й контакти не додавати в публічний GitHub. Ці файли не імпортуються у frontend і не копіюються в `public`/`dist`.

Обов’язкові поля: продавець/країна та вихідне посилання; модель/категорія; матеріал; об’єм або релевантні розміри; комплектація; закупівельна ціна/валюта; дата перевірки доступності ISO8601 із часовою зоною та підтвердження; права на кожне фото/власник/посилання на дозвіл. Нерелевантне поле позначити у приватному реєстрі як N/A з поясненням. Порожнє поле не дорівнює підтвердженню.

| Публічна подача | Підстава |
|---|---|
| Огляд категорії / Готуємо колекцію | Власна графіка + призначення. Без SKU товару, ціни, строку й покупки. |
| Конкретний товар / Під замовлення | Перевірений продавець/джерело, конкретна модель, характеристики/комплект, датована перевірка доступності, права на фото. Окремо затвердити публічну ціну й умови; не публікувати закупівельні дані. |
| Конкретний товар / У наявності | Усе вище + фізичне власне підтверджене кількісне надходження. Залишок продавця не означає власне «У наявності». |

На static staging всі продажі залишаються вимкненими. Форма не реалізує runtime товарний gate і не відкриває продажі. Не переводити статус автоматично лише після заповнення JSON. Потрібна окрема перевірка та авторизація комерційної публікації.

Власні SVG `src/editorial/CategoryArt.tsx` — схеми категорій, не фото моделей і не зображення підтвердженої комплектації. Права: створено для YUNELA у цьому завданні; сторонні фото не використовувалися. Візуалізація гравійованої чабані позначена концепцією. Конфігуратора, заявки, оплати й строків немає.
