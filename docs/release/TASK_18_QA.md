Это реальные CSS viewport приложения, не другая ширина и не масштабирование готовой картинки. Внешнее окно браузера нельзя изменить доступным API; аппаратная эмуляция устройства не заявляется. Прочие части страницы проверены переходами/DOM-измерениями и image validation. Полный network trace/настоящее touch-устройство не подменены console или тестами.
