# YUNELA — Avant-Garde Tea Editorial V1 / Acceptance

Дата: 13 октября 2026.
База: `feat/storefront-browser-staging`, `c3036cd7a56257040d4b40ebfb05dbbb61426337`.
Новая ветка: `feat/avant-garde-tea-editorial-v1`.

## Реализовано

- Тёмный кинематографичный первый экран с редакционной фотографией, крупной украинской типографикой и ясным переходом в каталог.
- Forest / charcoal / vermilion / ivory / amber; категории в модульной сетке, контрастная история бренда и акценты без китайского декоративного китча.
- Компактная шапка, поиск, корзина со счётчиком, mobile menu; оператор вынесен в footer.
- Фильтры категорий и наличия, поиск по отображаемому названию/имени поставщика/категории/SKU, реальные товарные фото, честные empty states.
- Карточка товара, корзина, checkout и статус заказа в единой системе. Переходы открывают нужный экран с начала страницы.
- Технические PHOTO-ID скрыты из клиентских заголовков и alt-текста. Нет придуманных цен, наличия, вкусовых свойств, отзывов или бестселлеров.
- WebP для 30 фото каталога (оригинальные JPEG сохранены), редакционный hero около 216 KiB. Нет внешнего запроса к Google Fonts.
- Tea Finder как навигация по направлению; отдельная честная информационная страница спецзаказа.
- Responsive 360 / 390 / 768 / 1440; клавиатурный фокус, skip link, reduced-motion, hover effects без блокировки покупок.

## Исправление тестового окружения

Первый полный прогон дал 203/206; 3 inventory concurrency теста упёрлись в тайм-ауты при многократном запуске Vite внутри worker. В финальном варианте `npm test` сначала собирает из тех же production-исходников два worker-модуля существующим Vite. Worker выполняют тот же код с реальной native SQLite. Проверки, 20 повторов гонок, барьеры, исходные тайм-ауты и production-сервисы не изменены. Новый framework и новые зависимости не добавлены. Генерируемые `artifacts/` исключены из ESLint наравне с `dist/`; исходники по-прежнему проверяются. После этого полный набор прошёл 206/206 с кодом выхода 0.

Обычный Chromium не запустился из-за запрета Unix-сокета окружением. Для реального E2E использован официальный Chrome Headless Shell 134 с существующим `YUNELA_CHROMIUM_PATH`; защита staging не ослаблялась. Установка native SQLite потребовала локальных Node 24.19.0 headers из-за ошибки ownership при штатной распаковке; версии зависимостей сохранены.

## Оставшиеся ограничения

1. Не подтверждены розничные цены, остатки, вес, происхождение и точные имена многих предложений. Покупка доступна только для подтверждённых предложений; E2E использует явно помеченный тестовый товар. Фото с неизвестным типом не назначены в Пуер по догадке.
2. Финальный утверждённый векторный wordmark отсутствует: сохранён текстовый YUNELA как fallback. Системные serif/sans имеют украинскую кириллицу; финальные брендовые шрифты не объявлены утверждёнными.
3. Tea Finder — выбор категории, не интеграция существующего domain recommendation engine. Приём заявок спецзаказа не подключён и это прямо указано в интерфейсе. Discovery Box/Profile остаются в существующем lab.
4. Приложение сохраняет существующие in-memory views на `/`, отдельные deep links для товара/checkout не добавлялись. `/#/lab` сохранён.
5. Публичного staging URL нет: постоянный host / HTTPS origin не предоставлены. Native Node/SQLite нельзя разместить как статический Site без изменения backend; конфигурация закрытого staging сохранена.
